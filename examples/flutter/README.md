# Fluent 2 · Flutter catalog

Interactive examples of all 24 Fluent 2 Native component families.

```bash

```

Use search and category filters to explore components, choose Web/Teams light/dark themes and compact sizing, validate inputs, change selections, and try the asynchronous workspace dialog.
